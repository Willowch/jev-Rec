# GSPO 第二阶段本机验证

已从 Qwen embedding 实验第一阶段 checkpoint 出发，完成 3 次 GSPO 优化器更新。测试和保存重载通过；这是工程短程验证，未据此宣称模型收敛或 Recall/NDCG 改善。

## 实际配置

- 历史启动命令为 `bash run.sh gspo`，环境为 WSL `Ubuntu-20.04` 中的 `work/openjev-env`。
- GPU：NVIDIA GeForce RTX 4080；PyTorch 2.8.0+cu128；注意力内核 chunk_gated_delta_rule。
- 输入：既有 Qwen3.5-2B 物品 embedding、3×255 SID、ML-1M 紧凑序列；未重新生成数据或码本。
- 初始化：`runs/qwen-embedding/stage1/checkpoint`；可训练参数 2,508,801，仅 LoRA 与 decision head。
- lr=2e-5、head-lr=1e-4、seed=43、candidate-batch=1、accumulation=1、max_history=20。
- G=4、每组复用 2 次更新、裁剪范围 0.9997–1.0004、NLL 权重 0.1；共采样 8 条完整三层轨迹，来自 2 个训练位置。
- 奖励为冻结 Qwen embedding 的历史相似度替代物，门槛 0；不是 GenRec 的 SIM 模型。

新组第一步的比值为 1，标准化优势均值接近 0，因此 GSPO 标量损失接近 0；非零策略梯度说明 RL 项确实参与优化。第二步复用相同旧概率与奖励，序列裁剪已在真实模型更新中执行。

本次第 2 步四条序列全部触发有效裁剪，策略梯度为 0，该步由 NLL 更新。这是当前学习率和较窄裁剪范围下的观测结果；正式训练应通过验证集评估学习率、裁剪范围和 rollout 复用次数，不能把本次默认值视为已调优配置。

- LoRA 最大绝对变化：6.01187348e-05；head 最大绝对变化：0.000300325453。
- checkpoint 重载 logits 最大绝对误差：0。
- 校准温度：20，只使用 3 条独立 calibration 决策，按目录支持集拟合。
- 训练、校准和重载总耗时：316.6 秒（不含首次加载）；训练峰值已分配张量显存 4.123 GiB。

校准温度达到搜索上界 20；这次仅用 3 条校准样本，不能认为概率已可靠校准，正式训练需扩大校准样本并检查留出集表现。
